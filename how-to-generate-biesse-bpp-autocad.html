How to Generate a Biesse BPP Program From AutoCAD

Writing BPP files for Rover and Skipper from the parts you already modelled.

If you run a Biesse machine, the BPP file is the last step before the part gets made. Writing it usually means opening the machine's software and rebuilding a part that already exists — in full, in 3D, in your AutoCAD drawing.

What normally happens between drawing and machine

The part is modelled in AutoCAD with all its drilling. Then someone opens the CAM software, creates a new part, types the dimensions, and places the holes again by coordinate. The information was complete before that started; it was simply in a format the machine could not read.

It is slow, and it is exactly the kind of repetitive transcription where a 32 mm spacing quietly becomes 37 mm on one panel out of sixty.

This is not another CAM package

Most Biesse CNC software discussions end up being about which CAM system to buy alongside your CAD. WoodPrep is not that: it does not replace bSolid or Biesse Works, and there is nothing new to learn. It runs inside AutoCAD and writes the BPP file from the part you already modelled — AutoCAD to CNC in one step, with the drawing staying the single source.

Write the BPP directly

The EE26 command reads the selected part and writes the BPP program for Biesse Skipper or Rover: size, grain direction, edge banding and the full hole pattern, taken from the model itself. The same run appends the part to cnc_import.txt, so the cutting list and the machine files come from one source and stay consistent.

For a whole carcass, CABINET runs it on every part in a single pass — sixty parts become sixty programs without sixty manual entries.

Mirror pairs mean fewer programs

Cabinet sides and door pairs are mirror images of each other. Because WoodPrep recognises those pairs by dimensions and hole pattern, a mirrored pair is handled as a pair rather than as two unrelated parts — fewer programs to manage on the machine, and fewer opportunities to load the wrong one.

SCM as well

The same command also writes SCM format, so a workshop running both brands does not need a different route for each. The machine format is matched to your specific machine during setup.

What you end up with
