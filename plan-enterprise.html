Enterprise — Command Reference

All commands available in the Enterprise plan.

Biesse Rover Biesse Skipper SCM CNC
Production preparation
CALCE26
Included
Material & Hardware List

Generates a complete material and hardware summary from the drawing. Output files are Excel-importable: alapanyag.txt (board list) and vasalat.txt (hardware list).

SIZEE26
Included
Bounding Size

Reads the bounding box of the selected solid — X, Y, and thickness — and copies the values to the clipboard.

Part processing & automation
CABINET
Included
Batch Carcass Processing

Processes all parts of a carcass in one operation. Runs EE26 for each part automatically and collects the full CNC output.

IDENTICAL
Included
Find Identical Parts

Detects parts with matching size and hole pattern. Highlights them and marks them as a group. Available as a standalone command and inside CABINET batch.

IDENTICAL_RESET
Included
Reset Identical Coloring

Clears the color highlighting applied by IDENTICAL.

MIRRORPAIR
Included
Detect Mirror Pairs

Finds left–right mirrored part pairs to reduce CNC programs and optimise nesting. Available as a standalone command and inside CABINET batch.

MIRRORPAIR_RESET
Included
Reset Mirror-Pair Coloring

Clears the color highlighting applied by MIRRORPAIR.

FINALIZEJOINTS
Included
Finalize Joints

Subtracts all $DIFF_ helper solids from the carcass using Boolean operations. Run this before exporting to ensure accurate geometry.

SUBTRACTBACK
Included
Subtract Back Panel

Subtracts the back panel recess from the carcass body. Run once after designing the back groove.

Cabinet design
CORPUS_CREATION
Included
Parametric Cabinet Generator

Generates a complete carcass from parameters: doors (overlay & inset, left & right), drawers with Blum slide boxes, auto-positioned hinges, shelf pins, and minifix connectors.

CORPUS_FROM_PLAN
Included
Generate from Floor Plan

Reads room dimensions from an existing floor plan drawing and generates the carcass geometry automatically.

CNC machine output
EE26
CNC output
Full Part Data + CNC / BPP Output

Processes a single selected part and generates the complete CNC program file — BPP format for Biesse Skipper/Rover, or SCM format. Includes hole patterns, edgebanding, and grain direction.

WW26
CNC output
Quick Single-Part BPP Output

Sends the selected part directly to the CNC machine without opening any dialog. Fastest path from drawing to machine.

BPP_CHECK
CNC output
Hole Pattern Check

Validates the hole pattern on the selected part and lists all detected holes. Use to verify CNC output before sending to the machine.

BREP_DEBUG
Dev / debug
Hole Detection Debug

Developer-level diagnostic tool for inspecting the B-rep solid and troubleshooting hole detection issues.

Utilities
SHOWALLE26
Included
Show All Hidden Parts

Reveals all hidden objects in the current drawing at once.
