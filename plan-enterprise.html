Production preparation
CALCE26Included
Material List
Collects all board parts from the drawing and writes the material list file. Open the Excel companion workbook and click Import Parts to load the full cutting list with sizes and quantities.
CALCE26Included
Hardware List
Scans all VAS_ layers in the drawing and builds the complete hardware list. Open the Excel companion workbook and click Import Hardware to insert all items with quantities.
SIZEE26Included
Bounding Size
Reads the bounding box of the selected solid — X, Y, and thickness — and copies the values to the clipboard.
Part processing & automation
CABINETIncluded
Batch Carcass Processing → cnc_import.txt + CNC files
Iterates through every part of the carcass and runs EE26 on each one — no part can be missed. Simultaneously writes cnc_import.txt (for Excel import) and generates the CNC program file for each part. When all parts are done, open the Excel companion workbook and click Import Parts.

CNC machine output
EE26CNC output
Full Part Data → CNC file + cnc_import.txt
Processes a single selected part: records size, grain direction, edgebanding, and hole pattern — then writes the CNC program file (BPP for Biesse Skipper/Rover, or SCM format) and appends the line to cnc_import.txt. Use CABINET to run this on every part automatically.
