WoodPrep

Professional — Command Reference

All commands available in the Professional plan.

Production preparation
CALCE26
Included
Material & Hardware List

Generates a complete material and hardware summary from the drawing. Output files are Excel-importable: alapanyag.txt (board list) and vasalat.txt (hardware list).

PP26
Included
Part Data Sheet + CNC Import Line

Processes a single selected part. Records size, grain direction, and edgebanding on all four edges. Also writes the CNC import line to the output file.

SIZEE26
Included
Bounding Size

Reads the bounding box of the selected solid — X, Y, and thickness — and copies the values to the clipboard.

Part processing & automation
CABINET
Included
Batch Carcass Processing

Processes all parts of a carcass in one operation. Runs PP26 for each part automatically and collects the full output.

IDENTICAL
Batch only
Find Identical Parts

Detects parts with matching size and hole pattern. Highlights them and marks them as a group. Runs automatically inside CABINET — not available as a standalone command in this plan.

MIRRORPAIR
Batch only
Detect Mirror Pairs

Finds left–right mirrored part pairs to reduce CNC programs and optimise nesting. Runs automatically inside CABINET — not available as a standalone command in this plan.

FINALIZEJOINTS
Included
Finalize Joints

Subtracts all $DIFF_ helper solids from the carcass using Boolean operations. Run this before exporting to ensure accurate geometry.

SUBTRACTBACK
Included
Subtract Back Panel

Subtracts the back panel recess from the carcass body. Run once after designing the back groove.

Cabinet design
CORPUS_CREATION
Included
Parametric Cabinet Generator

Generates a complete carcass from parameters: doors (overlay & inset, left & right), drawers with Blum slide boxes, auto-positioned hinges, shelf pins, and minifix connectors.

CORPUS_FROM_PLAN
Included
Generate from Floor Plan

Reads room dimensions from an existing floor plan drawing and generates the carcass geometry automatically.

Utilities
SHOWALLE26
Included
Show All Hidden Parts

Reveals all hidden objects in the current drawing at once.
