How to Generate a Cabinet From a Floor Plan in AutoCAD

Using the room drawing you already have as the starting point for the carcass.

The job usually starts with a floor plan: the room measured, the walls drawn, the run marked out. Then the cabinet gets modelled — and the same dimensions get typed in a second time, by hand, into a new drawing.

The second entry is where the error creeps in

Nothing is wrong with the floor plan; it was measured on site and it is correct. The risk is in the copying. A wall that is 2 840 mm on the plan becomes 2 480 mm in the cabinet model, and nobody notices until the units are on the van.

It is also simply slow. Re-entering dimensions you already have is the kind of work that feels like progress but produces nothing new.

Read the plan instead of retyping it

The CORPUS_FROM_PLAN command takes the room dimensions from the existing floor plan drawing and generates the carcass geometry from them. The plan stays the single source of truth — if the wall is 2 840, the cabinet is built to 2 840, because it was never typed in twice.

Step by step

Start from the floor plan you already drew

The room layout from the site survey — no special preparation needed.

Run CORPUS_FROM_PLAN

The room dimensions are read from the drawing and the carcass geometry is generated to match.

Adjust as an ordinary model

What comes out is normal AutoCAD geometry. Edit it, add drawers, change a divider — nothing is locked.

Carry on to the cutting list

Run CABINET on the result and the parts go through to Excel like any other drawing.

What you end up with

  • Cabinet dimensions taken from the measured plan, not re-entered
  • One source of truth for the room size
  • Editable geometry, not a locked block
  • A model that flows straight into the cutting list and the CNC output
